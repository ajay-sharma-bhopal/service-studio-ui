# service-studio-ui

A Claude Code skill for driving the OutSystems Service Studio 11 desktop UI through the windows-mcp tools. It covers opening a module from the server, Manage Dependencies, 1-Click Publish, closing a module, and finding elements.

## Install

1. Copy the `service-studio-ui` folder into `%USERPROFILE%\.claude\skills\`.
2. Set up the prerequisites listed in `service-studio-ui/SKILL.md` (windows-mcp, and optionally the servicestudio MCP).
3. Start a new Claude Code session.

Optional: add `service-studio-ui/references/local-setup.md` with your own monitor layout, click positions and environment details to make it faster. Don't commit that file; it's in `.gitignore`.
